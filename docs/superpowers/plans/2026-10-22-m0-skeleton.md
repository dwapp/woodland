# Woodland M0（可编译骨架）实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 搭建 woodland 的可编译、可运行最小骨架：meson 构建系统 + wlroots wrap 依赖 + 日志工具 + server 初始化/启动/干净退出，headless 后端下空跑成功。

**架构：** 纯 C11 单体合成器（sway/labwc 风格）。M0 只落地骨架：`include/`（公开头）+ `src/`（实现）+ `subprojects/`（wrap 依赖）+ `tests/`。核心是 `struct woodland_server` 全局状态 + `woodland_server_init/start/run/finish` 生命周期四函数。

**技术栈：** C11、meson（>=1.3）、wlroots 0.20.2（meson wrap 下载）、wayland-server、wlr_scene。

**规格：** `docs/superpowers/specs/2026-10-22-woodland-design.md`
**骨架规划：** `docs/superpowers/2026-10-22-woodland-skeleton.md`（本计划实现其 M0 里程碑）

## 全局约束

- 每个新文件顶部包含 `// SPDX-License-Identifier: GPL-2.0-only`（M0 版权行统一省略，仅 SPDX 行；后续统一补充版权行）。
- 语言标准 `c_std=c11`；编译参数 `-DWLR_USE_UNSTABLE -D_POSIX_C_SOURCE=200809L`。
- `warning_level=2` + `werror=true`：警告即错误。
- wlroots 经 `subprojects/wlroots.wrap` 下载，锁定 `revision = 0.20.2`，pkg-config 名 `wlroots-0.20`。
- scenefx 经 `subprojects/scenefx.wrap` 下载（M0 不启用，仅放 wrap 文件占位，`required: get_option('effects')` 且 effects 默认 disabled）。
- 特性开关经 `configure_file` 生成 `config.h`，用 `WOODLAND_HAVE_*` 宏。
- 依赖可用性由 meson 自动下载（不设 `wrap_mode=nodownload`，让 meson 在首次 `setup` 时自行下载 wrap 依赖）。
- 使用 wlroots 自带的 `wl_list` 与 `wlr_log`，不另造链表/日志轮子（YAGNI）。
- 单实例全局 `struct woodland_server`（labwc 模式），模块间通过指针传递，不做依赖注入框架。

## 审查重点（Review Focus）

1. **无 GPU/无输出环境**：`WLR_BACKENDS=headless WLR_RENDERER=pixman` 下必须能启动并空跑，不能因 renderer 创建失败崩溃。→ 冒烟测试覆盖。
2. **干净退出**：收到 SIGTERM/SIGINT 必须退出且返回码为 0，不能挂死或非零退出。→ 冒烟测试覆盖。
3. **无输出空跑**：headless 且无任何 output 时事件循环必须稳定运行（不被空场景卡死）。→ 冒烟测试覆盖。
4. **资源释放顺序**：finish 必须按 scene → allocator → renderer → backend → display 逆序释放，不能 double-free 或泄漏。→ 冒烟测试的 ASan 变体覆盖。
5. **首次构建的依赖下载**：全新 clone 执行 `meson setup` 时 wlroots 经 wrap 自动下载成功，离线环境报错信息清晰。→ 构建步骤覆盖。

```meson
project('woodland', 'c',
  version: '0.1.0',
  license: 'GPL-2.0-only',
  meson_version: '>=1.3',
  default_options: [
    'c_std=c11',
    'warning_level=2',
    'werror=true',
  ],
)

add_project_arguments([
  '-DWLR_USE_UNSTABLE',
  '-D_POSIX_C_SOURCE=200809L',
], language: 'c')

# scenefx（随 effects 选项，M0 默认不启用）
subproject('scenefx', required: false)
scenefx = dependency('scenefx-0.5', fallback: 'scenefx',
                     required: get_option('effects'))

# wlroots（锁定 0.20.x）
wlroots_version = ['>=0.20.0', '<0.21.0']
subproject('wlroots', default_options: ['examples=false'],
           required: false, version: wlroots_version)
wlroots = dependency('wlroots-0.20', version: wlroots_version,
                     fallback: 'wlroots')

wayland_server = dependency('wayland-server')

# 特性开关 → config.h
conf_data = configuration_data()
conf_data.set10('WOODLAND_HAVE_EFFECTS',
                get_option('effects').enabled() and scenefx.found())
configure_file(output: 'config.h', configuration: conf_data)

subdir('include')
subdir('src')
subdir('tests')
```

`tests/smoke/run_headless.sh`：

```sh
#!/usr/bin/env sh
set -eu

BIN="${1:-./build/woodland}"
[ -x "$BIN" ] || { echo "binary not found: $BIN" >&2; exit 125; }

WLR_BACKENDS=headless WLR_RENDERER=pixman "$BIN" &
pid=$!

# 等待事件循环就绪
sleep 1
kill -TERM "$pid" 2>/dev/null || true

# 最多再等 5 秒退出
i=0
while kill -0 "$pid" 2>/dev/null && [ "$i" -lt 50 ]; do
    sleep 0.1; i=$((i+1))
done

if kill -0 "$pid" 2>/dev/null; then
    kill -KILL "$pid" 2>/dev/null || true
    wait "$pid" 2>/dev/null || true
    echo "woodland did not exit on SIGTERM" >&2
    exit 1
fi

wait "$pid"
```

- [ ] **步骤 3：实现 `include/woodland.h` 中的 `struct woodland_server`**

```c
struct woodland_server {
    struct wl_display *display;
    struct wl_event_loop *event_loop;
    struct wlr_backend *backend;
    struct wlr_renderer *renderer;
    struct wlr_allocator *allocator;
    struct wlr_scene *scene;
};
```

- [ ] **步骤 4：实现 `include/server.h` 中的生命周期接口**

```c
struct woodland_server;

bool woodland_server_init(struct woodland_server *server);
bool woodland_server_start(struct woodland_server *server);
int  woodland_server_run(struct woodland_server *server);
void woodland_server_finish(struct woodland_server *server);
```

- [ ] **步骤 5：实现 `src/server/server.c`**

按 labwc / scene-graph 示例的顺序实现：

`woodland_server_init`：
1. `wl_display_create()`；取 `wl_display_get_event_loop()`。
2. `wl_display_set_default_max_buffer_size(display, 1024*1024)`。
3. 注册信号：`wl_event_loop_add_signal(event_loop, SIGINT/SIGTERM, handle_terminate, display)`，`handle_terminate` 调 `wl_display_terminate(display)`；`signal(SIGPIPE, SIG_IGN)`。
4. `wlr_backend_autocreate(event_loop, &session)`（`session` 用局部变量，不存储——由 backend 持有，随 backend 销毁）。
5. `wlr_renderer_autocreate(backend)`；失败则报错返回 false。
6. `wlr_allocator_autocreate(backend, renderer)`；失败则报错返回 false。
7. `wlr_scene_create()`。
8. 每步失败用 `wlr_log(WLR_ERROR, ...)` 报错并返回 false。

`woodland_server_start`：
1. `wl_display_add_socket_auto(display)`；失败返回 false。
2. `wlr_backend_start(backend)`；失败返回 false。

`woodland_server_run`：`return wl_display_run(display);`

`woodland_server_finish`：逆序释放——`wlr_scene_node_destroy(&scene->tree.node)` → `wlr_allocator_destroy` → `wlr_renderer_destroy` → `wlr_backend_destroy` → `wl_display_destroy`。每个指针先判空再释放（幂等）。

- [ ] **步骤 6：实现 `src/main.c` 入口**

```c
int main(int argc, char *argv[]) {
    (void)argc; (void)argv;
    woodland_log_init(WLR_INFO);

    struct woodland_server server = {0};
    if (!woodland_server_init(&server)) return 1;
    if (!woodland_server_start(&server)) {
        woodland_server_finish(&server);
        return 1;
    }
    int ret = woodland_server_run(&server);
    woodland_server_finish(&server);
    return ret;
}
```
