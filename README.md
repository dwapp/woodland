# Woodland

Woodland is a lightweight, general-purpose Wayland compositor built for efficiency and simplicity.

## Goals

1. **Treeland Ecosystem & DDE**: Compatible with the treeland ecosystem, capable of running the Deepin Desktop Environment (DDE) with standard single-user session support and unadorned visual effects.
2. **Modern & Lightweight Desktops**: First-class support for running Noctalia, Quickshell-based shells, and LXQt.
3. **Target Platforms**: Prioritizes deepin and Arch Linux distributions.

## Development Status

This project is developed with AI assistance, primarily utilizing **Gemini 3.8 Flash** and **DeepSeek V4.1 Flash**.

Woodland is actively under development and is **not recommended for production use**.
